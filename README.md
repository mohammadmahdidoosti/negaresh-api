# Negaresh

Negaresh is an AI-powered editorial engine that turns raw Persian text into clear, well-structured, publication-ready
writing. Built for right-to-left (RTL) Persian content, it applies humanization and E-E-A-T (experience, expertise,
authority, trust) principles to every piece — preserving the facts you give it, and flagging what still needs a real
author's voice instead of inventing it.

Negaresh is an editorial aid, not a guarantee of rankings, factual accuracy, or AI-detection evasion.

## What it does

- Rewrites Persian source text into clean, readable Markdown
- Adapts to your chosen voice, content type, and quality level
- Flags missing experience, examples, or sources rather than fabricating them
- Runs automated quality and authenticity checks before content is marked ready for human review
- Tracks usage and cost privately, entirely within your own environment

## Philosophy

Negaresh follows people-first content principles: useful, original, clearly human-reviewed writing — never mass-produced
filler, and never a substitute for genuine expertise or verification.

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open the app locally and connect any OpenAI-compatible language model provider — Negaresh is provider-agnostic by
design.
